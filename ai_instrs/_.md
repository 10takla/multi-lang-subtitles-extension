## Создание расширения

**Задача:** написать расширение Chrome, который будет захватывать все субтитры к видео и отображать их строка за строкой.

**Интерфейс:**
- единная **панель управления** поверх страницы

**Функции:**
- мультисубтитры.

   **Ключевые элементы:**
   - **Селектор языка:** выбираем источник. В качестве источника один из списка субтитров доступных к видео. По умолчанию первый из списка.
   - **Селектор языка:** нажимаем "+" появляется выбор нового языка, появляется селектор:
      - Перевод с выбором языка. Выбор источника, выбор языка перевода. Для перевода используется Google Translate по [](./Исследование/Вопросы.md#движок-перевода).
      - Выбор субтитра из списка субтитров доступных к видео.
   - **Опция видимости:** С каждым **селектором языка** кнопка видимости.
   
   **Функции:**
   - Языки отображаются списком сверху вниз. Если у языка включена видимость то он отображается, если выключена то нет.
   - Можно менять порядок **селекторов языка** перетаскиванием - также меняется порядок отображения сбутитров.
   - Субтитры отображаются на самом видео, подстраиваясь под любой масштаб. В **панели управления** добавить иконку управления позиционирования субтитров. Основные свойства: отображение сбутитров в рамках окна видео.


Сильно не старайся по оформлению. Главное реализовать логику, чтобы я смог это проверить.

Файлы расширения создавай в [](../extension).

## Цикл проверки и исправления расширения

**Предварительное условие:** пользователь один раз устанавливает распакованное расширение из [../extension](../extension) в Chrome (`chrome://extensions`, включить «Режим разработчика» -> «Загрузить распакованное»).

1. Запусти локальный сервер для тестового стенда (`http://localhost:8000/test.html`).
2. Открой тестовую страницу ([test.html](../test/test.html)) через Chrome MCP (`navigate_page` на `http://localhost:8000/test.html`).
3. Проверь результат:
   - Сделай скриншот (`take_screenshot`) и проверь наличие субтитров в UI.
   - Запроси логи консоли (`list_console_messages`) на предмет ошибок.
   - Проверь внедрение скрипта через `evaluate_script` (`() => Boolean(window.__subtitlesCapturerInjected)`).
4. Если субтитры не появились или есть ошибки:
   - Исправь код расширения в [../extension](../extension).
   - Обнови тестовую страницу через Chrome MCP (`navigate_page`) и повтори шаг 3 до успешного результата.
