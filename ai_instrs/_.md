## Разработка расширения

**Задача:** написать расширение Chrome, который будет захватывать все субтитры к видео и отображать их с переводом или без строка за строкой.

**Интерфейс:**
- единая `панель управления` (строго 1 экземпляр):
   - иконка на видео и кнопка в попапе управляют одним и тем же единственным экземпляром `панели управления`, исключая появление второго экземпляра.
   
   В `панель управления` в хедере:
   - `переключатель субтитров`: включение/выключение отображения субтитров.
   - `Кнопка общих стилей`. Открывает в панели настройки стилей после настроек `суб-списка`:
      - `подложка текста суб-списка` - подоложка для текста всего `суб-списка` вместе. Если включен, то появляются вбор: цвет, контур, padding
      - `подложка текста селекторов` - подоложка для текста каждого селектора индивидуально. Если включен, то появляются вбор: цвет, контур, padding
      - gap между текстами `суб-списков`
      - максимальная ширина `текста суб-списка`: 0-100% от ширины `детект-окна видео` (по умолчанию 100%). Использует `Эффект изменения размеров блоков` из раздела "Эффекты".
      - выравнивание `текста суб-списка` (по умолчанию `left`)
      - `выбор шрифта`:
         - `Селектор вида стиля`. Выбор одного из стиля меняет отображение настроек:
            - готовый стиль шрифта: Base, или как у: Netflix, YouTube и тюп
            - свой: шрифт, выбор начертания: полужирный, курсив, и т.п.
         - размер: слайдер + `A-A+`


**Эффекты:**
- `Эффект изменения размеров блоков`. Если размер блока регулируется инструментом, но при этом прямое отобржаение изменения блока не видно, то появляется скелет блока, по которому мы видим как он меняется.
Также при наведении на этот инструмент должен появялеться этот скелет

- у каждого `детект-окна видео`, где детектируются субтитры, сбоку отображается лаконичная иконка. При нажатии отображает или скрывает (по умолчанию скрывает) `панель управления`. `панель управления` расположена и перемещается только в рамках `детект-окна видео`.

**Функции:**
- мультисубтитры.

   **Логические элементы:**
   - `Суб-список`: cписок субтитров доступных к видео.
   - `Детект-окно видео`: само окно видео, к которому принадлежат субтитры. С учетом масштабирования, режима окна: полноэкранный или нет.

   **Ключевые элементы:**
   - `Селектор языка`. Содержит элементы расположеные в порядке:
      - **Элементы перетаскивания:**
         - Элемент для зажатия и toggle перетаскивания.
            Можно менять порядок `селектора языка` в `суб-списке` перетаскиванием - также меняется порядок отображения сбутитров.
         - Стрелки верх/вниз/верх-вниз для смены порядка `селектора языка` в `суб-списке`
      - **Опция видимости:** У каждого `селектора языка` кнопка видимости, которая решает будет ли текущий `селектор языка` включен в `суб-список` отображаемых субтитров.
      - **Кнопка стилей** для текста субтитра только текущего `селектора языка`. Повторяет общие стили из `Кнопка общих стилей`, только для каждой настройки Inherit от соответствующей настройки или своя настройка. Только эти настройки:
         - `выбор шрифта`
         - `подложка текста селекторов`
            
      - Тип селектора один из:
         - Выбор субтитра из `суб-списка`. По умолчанию первый элемент.
         - `Перевод-селектор языка` включает в себя:
            - Перевод с выбором языка. Выбор из `суб-списка`, выбор языка перевода. 
            - Выбор движка перевода (по умолчанию первый) с индивидуальными максимумами одного запроса:
               - Google Translate (веб-эндпоинт без ключа) по [](./Исследование/Вопросы.md#движок-перевода) — максимум 1800 символов.
               - Yandex Translate (веб-эндпоинт без ключа) — повышенное качество для RU — максимум 10000 символов.
               - Chrome Built-in Translator (локальный API браузера без сети) — максимум 4000 символов.
            - `буфер перевода`: выбор лимита в символах (по умолчанию `Math.min(1000, максимум выбранного движка)`). Буфер строго ограничен сверху максимумом выбранного API. В буфер помещается максимальное целое число реплик, укладывающееся в лимит.

   - Нажимаем "+" появляется новый `селектора языка`:
   
   **Функции:**
   - Языки отображаются списком сверху вниз. Если у языка включена видимость, то он отображается, если выключена то нет.
   - Субтитры отображаются на самом видео (`детект-окно видео`).
      В `панели управления` флаг для отображения тега языка перед субтитром. По умолчанию выкл. Если вкл, то выравнивание по границе метки и субтитра.
      Если выкл, то выравнивание текста по левому краю.
      При этом сама панель в целом по умолчанию находится по центру.
      В `панели управления` добавить ползунки с вводом для x и y 0-100 процентного позиционирования субтитров. Основные свойства: отображение сбутитров в рамках окна видео.
   - **Упреждающий перевод:** для доступных дорожек видео реплики переводятся наперёд пачками целых реплик в пределах `буфер перевода` в символах, чтобы исключить задержку отображения перевода при воспроизведении.
   - **Независимость от нативных субтитров видео:** захват и отображение субтитров в расширении не зависят от состояния встроенных субтитров в плеере (включены они пользователем или выключены). Расширение никак не влияет на нативные субтитры и не переключает их состояние.

   **Поведения:**
   - если видео остановлено, таймлайн не движется, то субтитры не пропадают
   - **автоскрытие иконки на видео:** при воспроизведении иконка плавно скрывается через 2–3 секунды неактивности курсора над видео; при движении мыши над видео плавно появляется; при выходе за границы видео плавно скрывается за 1 секунду; на паузе или при открытой `панели управления` остаётся видимой
   - **индикация загрузки:** при асинхронной подгрузке субтитров или перевода отображай вместо ожидаемого текста строки Loading Spinner под размер её шрифта

Сильно не старайся по оформлению. Главное реализовать логику, чтобы я смог это проверить.

### Совместимость с Firefox на Android

- Поддержи единую кодовую базу без дублирования файлов и модулей.
- Добавь `browser_specific_settings.gecko` в [../extension/manifest.json](<../extension/manifest.json>).
- Используй Pointer Events (`pointerdown`, `pointermove`, `pointerup`) вместо Mouse Events для drag-and-drop и интерактивных элементов интерфейса.
- Предусмотри автоматический fallback на сетевые переводчики при отсутствии API локального перевода Chrome.

#### Проверка совместимости

1. Проверь манифест и код через `npx web-ext lint` на отсутствие ошибок спецификации Gecko.
2. Проверь тач-события и адаптивность в Chrome MCP с включенной эмуляцией мобильного экрана (`emulate` с `hasTouch: true`).
3. При необходимости выполни финальную проверку на устройстве через `npx web-ext run --target=firefox-android` или `about:debugging`.

#### Гайд проверки на Andoitd
- собрать [](../extension/build/subtitles.xpi)
- about:config -> xpinstall.signatures.required -> false
- В Nightly: Настройки → О Firefox Nightly → 5 раз тапните по логотипу. Появится пункт «Установить расширение из файла», выберите ваш файл xpi.

## Цикл проверки и исправления расширения

1. Запусти локальный HTTP-сервер для стендов расширения в [../extension](<../extension>).
2. Открой целевой тестовый стенд (`extension/modules/capturers/<категория>/<capturer>/test/index.html`) через Chrome MCP (`navigate_page`).
3. Проверь результат:
   - Проверь внедрение расширения через `evaluate_script` (`() => Boolean(window.__subtitlesCapturerInjected)`).
   - Проверь статус тестов в `window.__TEST_RESULTS__`.
   - Запроси логи консоли (`list_console_messages`) на предмет ошибок.
   - Сделай скриншот (`take_screenshot`) и проверь отображение субтитров в панели и на видео.
4. Если субтитры не появились или есть ошибки:
   - Исправь код расширения в [../extension](<../extension>).
   - Обнови тестовую страницу через Chrome MCP (`navigate_page`) и повтори проверку до успешного результата.

## Оптимизация

Работай над оптимизацие расширения, не затрагивая бизнес-логику. Всё должно работать также в плане функций - мы не должны изменять логику нашего приложения. Но мы можем его переделать в плане кода для оптимизации. Именно этим ты должен заняться. Расширение не должно тормозить, нагружать системы, не должно выполнять ненужные процессы. Само расширение очень легкое и простое и выполняет прямые действия.
