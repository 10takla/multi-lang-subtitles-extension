## Разработка расширения

**Задача:** написать расширение Chrome, который будет захватывать все субтитры к видео и отображать их с переводом или без строка за строкой.

**Интерфейс:**
- единная `панели управления` поверх страницы
- иконка должна отображаться у каждого видео, где детектиться субтитры. При нажатии на иконку раскрывается
- у каждого `детект-окна видео` отображается сбоку лакончиная иконка. При нажатии отображает или скрывает (по умолчанию скрывает) `панели управления`. `панели управления` расположено и перемещается только в рамках `детект-окна видео`.

**Функции:**
- мультисубтитры.

   **Логические элементы:**
   - `Суб-список`: cписок субтитров доступных к видео.
   - `Детект-окно видео`: само окно видео, к которому принадлежат субтитры. С учетом масштабирования, режима окна: полноэкранный или нет.

   **Ключевые элементы:**
   - `Селектор языка`:
      - `Перевод-селектор языка` включает в себя:
         - Перевод с выбором языка. Выбор из `суб-списка`, выбор языка перевода. 
         - Выбор движка перевода (по умолчанию первый):
            - Google Translate (веб-эндпоинт без ключа) по [](./Исследование/Вопросы.md#движок-перевода).
            - Yandex Translate (веб-эндпоинт без ключа) — повышенное качество для RU.
            - Chrome Built-in Translator (локальный API браузера без сети).
         - `буфер перевода`: выбор времени в секунадх -  (по умолчанию 30 секунд)
         - 
      - Выбор субтитра из `суб-списка`. По умолчанию первый элемент.
      - **Опция видимости:** У каждого `селектора языка` кнопка видимости.
   - Нажимаем "+" появляется новый `селектора языка`:
   
   **Функции:**
   - Языки отображаются списком сверху вниз. Если у языка включена видимость то он отображается, если выключена то нет.
   - Можно менять порядок `селектора языка` перетаскиванием - также меняется порядок отображения сбутитров.
   - Субтитры отображаются на самом видео (`детект-окно видео`).
      В `панели управления` флаг для отображения тега языка перед субтитром. По умолчанию выкл. Если вкл, то выравнивание по границе метки и субтитра.
      Если выкл, то выравнивание текста по левому краю.
      При этом сама панель в целом по умолчанию находится по центру.
      В `панели управления` добавить ползунки с вводом для x и y 0-100 процентного позиционирования субтитров. Основные свойства: отображение сбутитров в рамках окна видео.
   - **Упреждающий перевод:** для доступных дорожек видео реплики переводятся наперёд (буфер на N секунд из `буфер перевода`), чтобы исключить задержку отображения перевода при воспроизведении.
   - **Независимость от нативных субтитров видео:** захват и отображение субтитров в расширении не зависят от состояния встроенных субтитров в плеере (включены они пользователем или выключены). Расширение никак не влияет на нативные субтитры и не переключает их состояние.

## Цикл проверки и исправления расширения

1. Запусти локальный HTTP-сервер для тестового стенда (`http://localhost:8000/test.html`).
2. Открой тестовую страницу ([test.html](<../test/test.html>)) через Chrome MCP (`navigate_page` на `http://localhost:8000/test.html`).
3. Внедри скрипты расширения из [../extension](<../extension>) на страницу через Chrome MCP (`evaluate_script` со списком модулей из [manifest.json](<../extension/manifest.json>)).
4. Проверь результат:
   - Проверь внедрение скриптов через `evaluate_script` (`() => Boolean(window.__subtitlesCapturerInjected)`).
   - Запроси логи консоли (`list_console_messages`) на предмет ошибок.
   - Сделай скриншот (`take_screenshot`) и проверь отображение субтитров в панели и на видео.
5. Если субтитры не появились или есть ошибки:
   - Исправь код расширения в [../extension](<../extension>).
   - Обнови тестовую страницу через Chrome MCP (`navigate_page`) и повтори шаги 3–4 до успешного результата.


### Для проверки других видео

YouTube не работает через Chrome MCP. Запрашивай у пользователя режи [/browser](slashCommand;browser).

Для других сайтов октрывай через Chrome MCP как в [](#цикл-проверки-и-исправления-расширения)
Если ты не можешь открыть видео сайта нативно, то останови проверку и сообщи об этой ошибке пользователю.
