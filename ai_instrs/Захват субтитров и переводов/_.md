## Цикл разработки модулей захвата субтитров

**Инструкции:**
- Бери **метод захвата** (`<capturer>`) из [](<./Исследование/Способы извлечения и унификации субтитров в Chrome/Ответ.md>).
- Определи категорию и реализуй модуль в `extension/modules/capturers/<категория>/<capturer>/index.js`, где `<категория>`:
  - `browser/` — данные уже в браузере (`video.textTracks`, `<track>`);
  - `network/` — расширение само скачивает и парсит (`hls`, `dash`, `file`, `cea608`);
  - `platform_adapters/` — доступ только через проприетарное API платформы (`youtube`, `vimeo`, `playerjs`, `lordfilm`, `multfan`, `southpark4u`);
  - `render/` — доступа к данным нет, наблюдаем за рендером (`dom`, `hardsub`).
- Выполни [](#разработка-теста-для-модуля-захвата).

## Разработка теста для модуля захвата

**Входные данные:**
- `capturer` — имя модуля захвата.
- `категория` — категория из [](#цикл-разработки-модулей-захвата-субтитров).
- `strategy` — способ захвата из [](<./Исследование/Способы извлечения и унификации субтитров в Chrome/Ответ.md>).

**Задача:** создать изолированный стенд `extension/modules/capturers/<категория>/<capturer>/test/index.html` для ручной проверки типа видео и автоматической валидации.

**Инструкции:**
- В `extension/modules/capturers/<категория>/<capturer>/test/test.js` реализуй сценарий проверки под `strategy` (фикстуры, запуск захвата, валидация `SubtitleTrack` и вывод `Passed` / `Failed`).
- В `extension/modules/capturers/<категория>/<capturer>/test/index.html`:
  - Размести видеоплеер под конкретный тип видео с локальными субтитрами.
  - Подключи точку входа расширения [content.js](<../../../content.js>) через `<script src="...">`.
  - Обеспечь визуальный контроль воспроизведения видео и субтитров.
- Проверь нормализацию результата: массив `cues` должен содержать корректные `startMs`, `endMs` и непустой `text`.

**Требования:**
- Модуль лежит в `extension/modules/capturers/<категория>/<capturer>/index.js`, стенд — в `extension/modules/capturers/<категория>/<capturer>/test/index.html`.
- Стенд подключает расширение целиком через его точку входа [content.js](<../../../content.js>).
- Запрещены внешние сетевые запросы: все данные мокаются локально.
- Стенд должен поддерживать ручное открытие в браузере и автоматическую проверку через Chrome MCP.
- Результат должен строго соответствовать единой модели `SubtitleTrack`.
