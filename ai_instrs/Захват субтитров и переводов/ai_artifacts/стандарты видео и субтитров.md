# Стандарты видео и субтитров в Chrome/Web

## Форматы субтитров

- **WebVTT (`.vtt`)** — официальный W3C-стандарт текстовых дорожек для HTML5 (`<track>`). Поддерживается браузерами нативно (`TextTrack`, `VTTCue`), включает разметку реплик, CSS-стилизацию и позиционирование.
- **TTML / DFXP / IMSC1 (`.ttml`, `.dfxp`)** — W3C XML-стандарт синхронизированного текста. Базовый формат для потокового вещания, Netflix и DASH (`application/ttml+xml`, `stpp`).
- **SRT (`.srt`)** — текстовый де-факто стандарт субтитров в интернете (номера, тайминги, текст). Нативно браузером не поддерживается, парсится плеерами через JS или конвертируется в WebVTT.
- **CEA-608 / CEA-708** — стандарты Closed Captions цифрового телевидения. В вебе инкапсулируются в HLS (MPEG-TS/SEI) и транслируются JS-плеерами в нативный `TextTrack`.
- **ASS / SSA (`.ass`)** — стандарт оформления субтитров с абсолютным позиционированием, векторной графикой и стилями. В браузере рендерится через Canvas/WebAssembly (libass).
- **DVB Subtitles / Teletext** — стандарты вещательного ТВ. Передаются в транспортных потоках стриминга, требуют JS/Wasm-демультиплексирования.
- **PGS / VobSub (`.sup`, `.sub/.idx`)** — растровые графические субтитры Blu-ray/DVD. В браузере отображаются только через кастомные Canvas-декодеры.
- **YouTube TimedText (JSON3 / XML)** — проприетарный веб-формат субтитров YouTube с пословными таймингами (`events`/`segs`).

## Стандарты видео, контейнеров и веб-доставки

- **HTML5 `<video>` / `<track>`** — спецификация WHATWG/W3C для встроенного воспроизведения медиа и субтитров через API браузера (`HTMLMediaElement`, `TextTrackList`, `TextTrack`).
- **Контейнеры MP4 (ISOBMFF) и WebM (Matroska)** — стандартные веб-контейнеры для воспроизведения видеокодеков (H.264/AVC, H.265/HEVC, VP9, AV1) и аудиокодеков (AAC, Opus).
- **HLS (HTTP Live Streaming, RFC 8216)** — протокол адаптивного потокового вещания от Apple. Субтитры передаются отдельными WebVTT-сегментами по m3u8 или встроены в медиапоток (CEA-608/708).
- **DASH (Dynamic Adaptive Streaming over HTTP, ISO/IEC 23009-1)** — международный стандарт адаптивного стриминга. Описывает субтитры в MPD-манифесте и передает чанками TTML/WebVTT (фрагментированный MP4/stpp).
- **CMAF (Common Media Application Format, ISO/IEC 23000-19)** — стандарт объединения HLS и DASH в единые фрагментированные fMP4 сегменты и субтитры (wvtt/stpp).
- **MSE (Media Source Extensions, W3C)** — браузерный API для программной подачи медиа-сегментов в `<video>` через JavaScript (основа hls.js, dash.js, Shaka Player).
- **EME (Encrypted Media Extensions, W3C)** — браузерный API для защищенного DRM-воспроизведения через CDM (Widevine в Chrome).
- **WebCodecs API (W3C)** — низкоуровневый доступ браузера к декодерам видеокадров и аудиодорожек.
- **WebRTC (W3C / IETF)** — стандарт потокового медиа реального времени с ультранизкой задержкой; текст/субтитры могут передаваться через DataChannel.
