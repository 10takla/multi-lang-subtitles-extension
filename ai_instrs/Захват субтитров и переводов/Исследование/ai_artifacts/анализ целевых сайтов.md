## 1. southpark4u.ru (Южный Парк)

* **URL:** `https://www.southpark4u.ru/episodes/yuzhnyj-park-2-sezon-2-seriya/`
* **Архитектура плеера:**
  * Реализован через `<iframe>` сторонних CDN:
    * Вкладка 1 («🔥CDN1»): `https://api.nextembed.ws/embed/...` на базе `player-venom`.
    * Вкладка 2 («Плеер 2»): `https://traff-as.stravers.live?...` на базе нативного `<video>` с HLS.
* **Как устроены субтитры:**
  * В коде CDN1 субтитры передаются явным параметром конфигурации:
    ```javascript
    source: {
      cc: [{ "url": "https://.../F3NIHIOA.vtt?...", "name": "Eng. full - 1" }]
    }
    ```
* **Способ захвата:**
  * Перехват URL файла субтитров `.vtt` внутри iframe через сетевой запрос или чтение конфигурации плеера.
  * Скачивание файла целиком за один сетевой запрос `fetch`.
* **Захват наперёд:** **Да**, отдаётся цельный VTT-файл на весь хронометраж эпизода.

## 2. south-park.mult-fan.tv (Южный Парк)

* **URL:** `https://south-park.mult-fan.tv/page.php?id=1514&voice=4`
* **Архитектура плеера:**
  * Плеер встроен прямо в DOM страницы без iframe: `<div id="player1514"></div>`.
  * Используется **Playerjs** (`https://mult-fan.tv/player/playerjs.js`).
* **Как устроены субтитры:**
  * Задаются в конструкторе `new Playerjs`:
    ```javascript
    subtitle: '[Вкл.]https://south-park.mult-fan.tv/captions/eng/15/1514.vtt'
    ```
* **Способ захвата:**
  * Прямое чтение ссылки из параметров плеера / кода страницы либо через сетевой перехват.
  * Скачивание полного `.vtt` файла за один сетевой запрос.
* **Захват наперёд:** **Да**, файл содержит полный таймлайн всех реплик.

## 3. hrabroe-serdcea-lordfilm.ru (Холодное сердце)

* **URL:** `https://hrabroe-serdcea-lordfilm.ru/film/holodnoe-serdcze-2013/`
* **Архитектура плеера:**
  * Реализован через `<iframe>` CDN-балансировщиков:
    * Плеер 1: `https://api.tobaco.ws/embed/movie/1465` (движок `player-venom`).
    * Плеер 2: `https://attorney-as.allarknow.online/?...` (Alloha / CDNMovies).
* **Как устроены субтитры:**
  * В конфигурации Плеера 1 (`tobaco.ws`) прописан массив из 4 дорожек:
    ```javascript
    source: {
      cc: [
        { "url": "https://.../AFFXZX7U.vtt?...", "name": "Eng. full - 1" },
        { "url": "https://.../KVSRMRGB.vtt?...", "name": "Рус. полные - 4" }
      ]
    }
    ```
* **Способ захвата:**
  * Считывание массива `cc` внутри iframe либо перехват сетевых запросов к `.vtt`.
  * Скачивание выбранной языковой дорожки целиком за один запрос.
* **Захват наперёд:** **Да**, полный список таймингов доступен сразу.

## Общие выводы

1. **Тип субтитров:** Все три сайта относятся к **Типу 2 (Кастомные веб-плееры с внешними `.vtt` файлами)**.
2. **Возможность захвата:** **100% возможность захвата** на всех ресурсах.
3. **Возможность упреждающего перевода:** На всех сайтах субтитры отдаются цельными файлами, что позволяет загружать тайминги на весь фильм/серию сразу и переводить скользящим буфером на 30–60 секунд вперёд.
4. **Требование к расширению:** Для сайтов 1 и 3 расширение должно работать внутри вложенных `iframe` (`"all_frames": true`).
