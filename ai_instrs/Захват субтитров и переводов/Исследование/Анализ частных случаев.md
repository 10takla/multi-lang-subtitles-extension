### Анализ переключения плееров

Видео из [](#целевые-видео) №1 и №3 имеют 2 плеера.
Выясни как происходит переключение между плеерами:
- это одно <video>, а переключение по JS?
- переключение по JS и в тот или иной момент на сайте только одно <video>?
- переключение по JS, но на сайте несколько <video>?
- переключение по HTML CSS?
и подобные вопросы.

Дай лаконичный и простой ответ в блоке ниже

----
#### 1. southpark4u.ru (№1)
* **Механизм переключения:** Чистый **HTML + CSS** без JS. Используются переключатели `<input type="radio" name="tabs">` и CSS-правила `:checked` для переключения видимости секций `<section>`.
* **Количество `<video>`:** Не одно. В DOM одновременно присутствуют **оба `<iframe>`**, внутри каждого из которых инициализируется **свой отдельный независимый тег `<video>`**. Неактивный плеер просто скрыт стилями.

#### 2. hrabroe-serdcea-lordfilm.ru (№3)
* **Механизм переключения:** **JS + CSS**. Обработчик клика на JS переключает класс `.current` между вкладками `.film-players__tab` и блоками `.film-player`, управляя их CSS-видимостью.
* **Количество `<video>`:** Не одно. В DOM одновременно присутствуют блоки всех плееров со своими `<iframe>`, внутри каждого загруженного фрейма работает **свой собственный `<video>`**.
