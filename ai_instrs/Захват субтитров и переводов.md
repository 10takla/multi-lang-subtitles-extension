Реализуй с учётом модульности (размещай их в подпапке `modules/capturers/`) и рефакторинга.

## Для YouTube

Выдели логику YouTube в отдельный изолированный модуль захвата.

**Алгоритм:**
1. **Получение дорожек:** без взаимодействия с UI плеера внедри скрипт в контекст страницы (`MAIN` world), прочитай список `captionTracks` из `window.ytInitialPlayerResponse` или `movie_player.getPlayerResponse()` и передай в расширение через `window.postMessage`.
2. **Загрузка таймингов:** выполни прямой сетевой `fetch` по `baseUrl` выбранной дорожки с параметром `&fmt=json3`, сохранив текст и тайминги всех реплик видео целиком.
3. **Перевод:** синхронизируй реплики с `video.currentTime` и переводи их скользящим буфером по таймлайну на 30–60 секунд вперёд.

## Для HTML5 видео (<track> / WebVTT)

- Переводи дорожки в скрытый режим (`track.mode = 'hidden'`) для подавления нативного рендера.
- Извлекай реплики напрямую из `track.cues` и переводи скользящим буфером по таймлайну на 30–60 секунд вперёд.

## Для кастомных веб-плееров (Playerjs, JW Player)

- Перехватывай URL файла субтитров (`.vtt`, `.srt`) через сетевые запросы или конфигурацию плеера (`window.playerjs.api`).
- Скачивай файл субтитров целиком за один сетевой запрос и переводи скользящим буфером на 30–60 секунд вперёд.

## Для потокового видео (HLS / DASH)

- Читай субтитры из `video.textTracks`, если плеер транслирует их в нативный API.
- Иначе перехватывай сетевые сегменты субтитров по мере их загрузки плеером; для live-трансляций переводи реплики без буфера наперёд.

## Для DRM VOD (Netflix, Кинопоиск)

- Реализуй изолированные адаптеры под каждый сервис через внутренние API плеера или перехват сетевых запросов таймингов.

## Для вшитых субтитров (Hardsub)

- Захватывай кадры видеопотока через `<canvas>` и распознавай текст в реальном времени с помощью OCR-модели.
